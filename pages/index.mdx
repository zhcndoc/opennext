# OpenNext

OpenNext 始于 2023 年，是一项开源计划，旨在使 Next.js 真正可移植——可部署在任何平台上，而不仅仅是 Vercel。最初由 [SST](https://sst.dev) 社区发起的 AWS Lambda 无服务器适配器，已发展成为由 [Cloudflare](https://developers.cloudflare.com/)、[Netlify](https://www.netlify.com/) 和更广泛的贡献者社区支持的多平台项目。

## 我们目前的进展

与 Vercel 合作，OpenNext 协助建立了部署适配器工作组，与 Cloudflare、Netlify、Google、AWS Amplify 等一起，为 Next.js 设计标准的 [部署适配器 API](https://nextjs.org/docs/app/api-reference/config/next-config-js/adapterPath)。该 API 目前在 **Next.js 16.2 中已稳定**，意味着平台不再需要逆向工程构建输出。

基于此官方 API，针对 AWS、Cloudflare 和 Netlify 的新适配器正在积极开发中。[阅读完整故事 →](/news/2026-03-25-3-years-of-opennext)。

截至 2026 年 3 月，OpenNext 成员现已加入 [Next.js 生态系统工作组](https://nextjs.org/ecosystem-working-group)，在那里他们继续与 Next.js 团队和其他合作伙伴协作。

## 适配器

1. [SST](https://sst.dev) 社区，维护 [AWS](aws) 适配器
2. [Cloudflare](https://developers.cloudflare.com/) 团队，维护 [Cloudflare](cloudflare) 适配器
3. [Netlify](https://www.netlify.com/) 团队，维护 [Netlify](netlify) 适配器
