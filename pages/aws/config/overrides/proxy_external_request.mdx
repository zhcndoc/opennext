此覆盖由 OpenNext 用于将重写的请求代理到外部服务。它在 `external` 中间件（如果已设置）中使用，或者在中间件被捆绑时在默认/分割服务器中使用。

如果你想更好地了解如何实现自己的 ProxyExternalRequest，最简单的方法是查看现有的 [包含的 ProxyExternalRequest](https://github.com/opennextjs/opennextjs-aws/tree/main/packages/open-next/src/overrides/proxyExternalRequest)。
