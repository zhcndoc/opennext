warmer 后端用于在无服务器架构中预热服务器 lambda。这有助于避免冷启动。

### 特殊事件和结果

```typescript
interface WarmerEvent {
  type: "warmer";
  warmerId: string;
  index: number;
  concurrency: number;
  delay: number;
}

interface WarmerResponse {
  type: "warmer";
  serverId: string;
}
```

### 特殊覆盖

#### 调用函数

您可以自定义 `invoke` 函数来处理 `warmer` 事件。默认情况下它使用 lambda invoke 命令。默认调用需要一个 `WARM_PARAMS` 环境变量，它是此内容的字符串化版本

```typescript
{
  concurrency: number;
  function: string;
}[]
```
