## 示例

要创建一个新的 Next.js 应用，预配置为使用 @opennextjs/cloudflare 在 Cloudflare 上运行，请运行：

```
npm create cloudflare@latest -- my-next-app --framework=next --experimental
```

### 基础入门项目

`@opennextjs/cloudflare` 包的仓库中包含两个基础示例应用：

- [_`create-next-app`_](https://github.com/opennextjs/opennextjs-cloudflare/tree/main/examples/create-next-app) — 一个使用 [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) 引导的 Next.js 项目。
- [_`api`_](https://github.com/opennextjs/opennextjs-cloudflare/tree/main/examples/api) — 一个具有单个 API 路由的最小化 Next.js 项目

你可以利用这些示例来了解如何配置你的 Next.js 应用以使用 `@opennextjs/cloudflare`，或者参考 [入门指南](/cloudflare/get-started)。
