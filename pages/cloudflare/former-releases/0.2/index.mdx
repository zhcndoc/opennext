## Cloudflare

[`@opennextjs/cloudflare`](https://www.npmjs.com/package/@opennextjs/cloudflare) 适配器允许你使用 [Next.js 的 Node.js“运行时”](https://nextjs.org/docs/app/building-your-application/rendering/edge-and-nodejs-runtimes) 将 Next.js 应用部署到 [Cloudflare Workers](https://developers.cloudflare.com/workers)。

<Callout>
[`@opennextjs/cloudflare`](https://www.npmjs.com/package/@opennextjs/cloudflare) 处于 1.0 之前版本，仍在积极开发中。你应该尝试它，[报告错误](https://github.com/opennextjs/opennextjs-cloudflare/issues)，[分享反馈](https://github.com/opennextjs/opennextjs-cloudflare/discussions)，并贡献代码以帮助使在 Cloudflare 上运行 Next.js 应用变得更加容易。我们目前还不建议将其用于任务关键型生产应用。

你也可以使用 [`@cloudflare/next-on-pages`](https://www.npmjs.com/package/@cloudflare/next-on-pages) 将 Next.js 应用部署到 Cloudflare Pages。你可以查看下方支持的 Next.js 功能差异，并通过查看 [`@cloudflare/next-on-pages` 的文档](https://developers.cloudflare.com/pages/framework-guides/nextjs/ssr/supported-features/)，以及 [此处](https://developers.cloudflare.com/workers/static-assets/compatibility-matrix/) 了解 Workers 和 Pages 之间的差异。

</Callout>

### 开始使用

##### 新应用

要创建一个新的 Next.js 应用，预配置为使用 @opennextjs/cloudflare 在 Cloudflare 上运行，请运行：

```
npm create cloudflare@latest -- my-next-app --framework=next --experimental
```

##### 现有的 Next.js 应用

遵循 [此处](/cloudflare/0.2/get-started) 的指南，在现有的 Next.js 应用中使用 [@opennextjs/cloudflare](https://www.npmjs.com/package/@opennextjs/cloudflare)。

### 支持的 Next.js 运行时

Next.js 拥有 [两种“运行时”](https://nextjs.org/docs/app/building-your-application/rendering/edge-and-nodejs-runtimes) —— "Edge" 和 "Node.js"。当你使用 `@opennextjs/cloudflare` 时，你的应用可以使用 Node.js 运行时，它功能更齐全，并允许你使用 Cloudflare Workers 运行时提供的 [Node.js APIs](https://developers.cloudflare.com/workers/runtime-apis/nodejs/)。

这与 `@cloudflare/next-on-pages` 有一个重要区别，后者仅支持 "Edge" 运行时。Next.js 中的 Edge Runtime 代码 [有意限制了可以使用哪些 Node.js APIs](https://github.com/vercel/next.js/blob/canary/packages/next/src/build/webpack/plugins/middleware-plugin.ts#L820)，并且 "Edge" 运行时不支持所有 Next.js 功能。

### 支持的 Next.js 版本

`@opennextjs/cloudflare` 处于 1.0 之前版本，仍在积极开发中。我们打算支持 Next.js 13 和 14 的所有次要版本和补丁版本，以及 Next.js 15 发布后的版本。（目前是发布候选版本）

为了帮助提高兼容性，我们鼓励你 [报告错误](https://github.com/opennextjs/opennextjs-cloudflare/issues) 并贡献代码！

### 支持的 Next.js 功能

- [x] [App Router](https://nextjs.org/docs/app)
- [x] [路由处理器](https://nextjs.org/docs/app/building-your-application/routing/route-handlers)
- [x] [动态路由](https://nextjs.org/docs/app/building-your-application/routing/dynamic-routes)
- [x] [静态站点生成 (SSG)](https://nextjs.org/docs/app/building-your-application/rendering/server-components#static-rendering-default)
- [x] [服务端渲染 (SSR)](https://nextjs.org/docs/app/building-your-application/rendering/server-components)

以下 Next.js 功能尚未支持 —— 但我们欢迎贡献和反馈！告诉我们你想看到什么，或者你想添加支持什么：

- [ ] [Pages Router](https://nextjs.org/docs/pages)（你应该使用 App Router 代替，它是在 Next.js 13 中引入的）
- [ ] [增量静态再生 (ISR)](https://nextjs.org/docs/app/building-your-application/data-fetching/incremental-static-regeneration)
- [ ] [部分预渲染 (PPR)](https://nextjs.org/docs/app/building-your-application/rendering/partial-prerendering)
- [ ] [中间件](https://nextjs.org/docs/app/building-your-application/routing/middleware)
- [ ] [图片优化](https://nextjs.org/docs/app/building-your-application/optimizing/images)（你可以通过遵循 [本指南](https://developers.cloudflare.com/images/transform-images/integrate-with-frameworks/) 将 Cloudflare Images 与 Next.js 集成）
- [ ] [实验性流式支持](https://nextjs.org/blog/next-15-rc#executing-code-after-a-response-with-nextafter-experimental)

### @opennextjs/cloudflare 的工作原理

OpenNext Cloudflare 适配器通过获取 Next.js 构建输出并转换它来工作，以便它可以在 Cloudflare Workers 中运行。

当你将 [@opennextjs/cloudflare](https://www.npmjs.com/package/@opennextjs/cloudflare) 作为依赖项添加到你的 Next.js 应用中，然后运行 `npx cloudflare` 时，适配器首先通过运行 `next build` 构建你的应用，然后将构建输出转换为你可以使用 [Wrangler](https://developers.cloudflare.com/workers/wrangler/) 在本地运行并部署到 Cloudflare 的格式。

你可以 [此处](https://github.com/opennextjs/opennextjs-cloudflare/blob/main/packages/cloudflare/src) 查看 @opennextjs/cloudflare 的代码，以了解其底层工作原理。
