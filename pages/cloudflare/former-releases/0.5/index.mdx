## Cloudflare

[`@opennextjs/cloudflare`](https://www.npmjs.com/package/@opennextjs/cloudflare) 适配器允许您使用 [Next.js 的 Node.js“运行时”](https://nextjs.org/docs/app/building-your-application/rendering/edge-and-nodejs-runtimes) 将 Next.js 应用部署到 [Cloudflare Workers](https://developers.cloudflare.com/workers)。

<Callout>
[`@opennextjs/cloudflare`](https://www.npmjs.com/package/@opennextjs/cloudflare) 处于 1.0 版本之前，仍在积极开发中。您应该尝试一下，[报告错误](https://github.com/opennextjs/opennextjs-cloudflare/issues)，[分享反馈](https://github.com/opennextjs/opennextjs-cloudflare/discussions)，并贡献代码以帮助简化在 Cloudflare 上运行 Next.js 应用的过程。我们还不完全建议将其用于关键任务生产应用。

您也可以使用 [`@cloudflare/next-on-pages`](https://www.npmjs.com/package/@cloudflare/next-on-pages) 将 Next.js 应用部署到 Cloudflare Pages。您可以在下方查看支持的 Next.js 功能差异，并通过查阅 [`@cloudflare/next-on-pages` 的文档](https://developers.cloudflare.com/pages/framework-guides/nextjs/ssr/supported-features/)，以及[在此处](https://developers.cloudflare.com/workers/static-assets/compatibility-matrix/) 了解 Workers 和 Pages 之间的差异。

</Callout>

### 开始使用

##### 新应用

要创建一个新的 Next.js 应用，并预配置为使用 `@opennextjs/cloudflare` 在 Cloudflare 上运行，请运行：

```
npm create cloudflare@latest -- my-next-app --framework=next --experimental
```

##### 现有的 Next.js 应用

请遵循 [此处](/cloudflare/get-started) 的指南，在现有的 Next.js 应用中使用 [@opennextjs/cloudflare](https://www.npmjs.com/package/@opennextjs/cloudflare)。

### 支持的 Next.js 运行时

Next.js 拥有 [两种“运行时”](https://nextjs.org/docs/app/building-your-application/rendering/edge-and-nodejs-runtimes) —— "Edge" 和 "Node.js"。当您使用 `@opennextjs/cloudflare` 时，您的应用应该使用 Node.js 运行时，它功能更齐全，并允许您使用 [Cloudflare Workers 运行时提供的 Node.js API](https://developers.cloudflare.com/workers/runtime-apis/nodejs/)。

这与 `@cloudflare/next-on-pages` 有一个重要区别，后者仅支持 "Edge" 运行时。Next.js 中的 Edge Runtime 代码 [故意限制了可以使用的 Node.js API](https://github.com/vercel/next.js/blob/canary/packages/next/src/build/webpack/plugins/middleware-plugin.ts#L820)，并且 "Edge" 运行时不支持所有 Next.js 功能。

### 支持的 Next.js 版本

`@opennextjs/cloudflare` 处于 1.0 版本之前，仍在积极开发中。我们打算支持 Next.js 15 的所有次要版本和补丁版本，以及 Next.js 14 的最新次要版本。

为了提高兼容性，我们鼓励您 [报告错误](https://github.com/opennextjs/opennextjs-cloudflare/issues) 并贡献代码！

### 支持的 Next.js 功能

某些 Next.js 功能尚未支持或未经过充分测试。
随着我们朝着发布 1.0 版本迈进，我们将更新此列表。

- [x] [App Router](https://nextjs.org/docs/app)
- [x] [路由处理器](https://nextjs.org/docs/app/building-your-application/routing/route-handlers)
- [x] [动态路由](https://nextjs.org/docs/app/building-your-application/routing/dynamic-routes)
- [x] [静态站点生成 (SSG)](https://nextjs.org/docs/app/building-your-application/rendering/server-components#static-rendering-default)
- [x] [服务器端渲染 (SSR)](https://nextjs.org/docs/app/building-your-application/rendering/server-components)
- [x] [中间件](https://nextjs.org/docs/app/building-your-application/routing/middleware)
- [x] [图像优化](https://nextjs.org/docs/app/building-your-application/optimizing/images)（您可以遵循 [本指南](https://developers.cloudflare.com/images/transform-images/integrate-with-frameworks/) 将 Cloudflare Images 与 Next.js 集成）
- [x] [部分预渲染 (PPR)](https://nextjs.org/docs/app/building-your-application/rendering/partial-prerendering)
- [x] [Pages Router](https://nextjs.org/docs/pages)
- [x] [增量静态再生 (ISR)](https://nextjs.org/docs/app/building-your-application/data-fetching/incremental-static-regeneration) <sup>1</sup>
- [x] [支持 after](https://nextjs.org/blog/next-15-rc#executing-code-after-a-response-with-nextafter-experimental)
- [ ] [可组合缓存](https://nextjs.org/blog/composable-caching) (`'use cache'`) 是 Next.js 15 的功能，目前尚不支持。

<sup>1</sup> 目前仅支持 `direct` 模式，且不适用于生产环境。

我们欢迎贡献和反馈！

### `@opennextjs/cloudflare` 的工作原理

OpenNext Cloudflare 适配器通过获取 Next.js 构建输出并对其进行转换，使其能够在 Cloudflare Workers 中运行。

当您向 Next.js 应用添加 [@opennextjs/cloudflare](https://www.npmjs.com/package/@opennextjs/cloudflare) 作为依赖项，然后运行 `npx opennextjs-cloudflare` 时，适配器首先通过运行 `package.json` 中的 `build` 脚本来构建您的应用，然后将构建输出转换为您可以使用 [Wrangler](https://developers.cloudflare.com/workers/wrangler/) 在本地运行并部署到 Cloudflare 的格式。

您可以 [在此处](https://github.com/opennextjs/opennextjs-cloudflare/blob/main/packages/cloudflare/src) 查看 `@opennextjs/cloudflare` 的代码，以了解其底层工作原理。
