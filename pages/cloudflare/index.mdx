## Cloudflare

[`@opennextjs/cloudflare`](https://www.npmjs.com/package/@opennextjs/cloudflare) 适配器允许您使用 [Next.js 的 Node.js“运行时”](https://nextjs.org/docs/app/building-your-application/rendering/edge-and-nodejs-runtimes) 将 Next.js 应用部署到 [Cloudflare Workers](https://developers.cloudflare.com/workers)。

### 快速开始

##### 新应用

要创建一个新的 Next.js 应用，并预配置为使用 `@opennextjs/cloudflare` 在 Cloudflare 上运行，请运行：

```
npm create cloudflare@latest -- my-next-app --framework=next --platform=workers
```

##### 现有 Next.js 应用

请遵循 [此处](/cloudflare/get-started) 的指南，在现有的 Next.js 应用中使用 [@opennextjs/cloudflare](https://www.npmjs.com/package/@opennextjs/cloudflare)。

### 支持的 Next.js 运行时

Next.js 拥有 [两种“运行时”](https://nextjs.org/docs/app/building-your-application/rendering/edge-and-nodejs-runtimes) —— "Edge" 和 "Node.js"。当您使用 `@opennextjs/cloudflare` 时，您的应用应该使用 Node.js 运行时，它功能更齐全，并允许您使用 Cloudflare Workers 运行时提供的 [Node.js API](https://developers.cloudflare.com/workers/runtime-apis/nodejs/)。

这与 `@cloudflare/next-on-pages` 有一个重要区别，后者仅支持 "Edge" 运行时。Next.js 中的 Edge 运行时代码 [故意限制了可以使用的 Node.js API](https://github.com/vercel/next.js/blob/canary/packages/next/src/build/webpack/plugins/middleware-plugin.ts#L820)，并且 "Edge" 运行时不支持所有 Next.js 功能。

### 支持的 Next.js 版本

支持 Next.js 16 的所有次版本和补丁版本，以及 Next.js 14 和 15 的最新次版本。
Next.js 14 的支持将于 2026 年第一季度停止。它已被 Next.js 团队 [不再支持](https://nextjs.org/support-policy#supported-versions)。

为了帮助提高兼容性，我们鼓励您 [报告 bug](https://github.com/opennextjs/opennextjs-cloudflare/issues) 并贡献代码！

### `@opennextjs/cloudflare` 的工作原理

OpenNext Cloudflare 适配器通过获取 Next.js 构建输出并对其进行转换来工作，以便它可以在 Cloudflare Workers 中运行。

当您向 Next.js 应用添加 [@opennextjs/cloudflare](https://www.npmjs.com/package/@opennextjs/cloudflare) 作为依赖，然后运行 `npx @opennextjs/cloudflare` 时，适配器首先通过运行 `package.json` 中的 `build` 脚本来构建您的应用，然后将构建输出转换为您可以使用 [Wrangler](https://developers.cloudflare.com/workers/wrangler/) 在本地运行并部署到 Cloudflare 的格式。

您可以 [此处](https://github.com/opennextjs/opennextjs-cloudflare/blob/main/packages/cloudflare/src) 查看 `@opennextjs/cloudflare` 的代码，以了解其底层工作原理。

### 关于 Worker 大小限制的说明

Cloudflare Worker 的大小限制在 Workers 免费计划上为 3 MiB，在 Workers 付费计划上为 10 MiB。构建 Worker 后，`wrangler` 将显示原始大小和压缩大小：

```
Total Upload: 13833.20 KiB / gzip: 2295.89 KiB
```

只有后者（压缩大小）计入 [Worker 大小限制](https://developers.cloudflare.com/workers/platform/limits/#worker-size)。
