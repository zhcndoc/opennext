## 示例

要创建一个新的 Next.js 应用，并预配置为使用 `@opennextjs/cloudflare` 在 Cloudflare 上运行，请执行：

```
npm create cloudflare@latest -- my-next-app --framework=next --platform=workers
```

### 基础入门项目

`@opennextjs/cloudflare` 包的仓库中包含了一些基础示例应用：

- [_`create-next-app`_](https://github.com/opennextjs/opennextjs-cloudflare/tree/main/examples/create-next-app) — 一个使用 [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) 引导的 Next.js 项目。
- [_`middleware`_](https://github.com/opennextjs/opennextjs-cloudflare/tree/main/examples/middleware) — 一个使用 middleware 的最小化 Next.js 项目
- [_`vercel-blog-starter`_](https://github.com/opennextjs/opennextjs-cloudflare/tree/main/examples/vercel-blog-starter) — 一个使用 SSG 的博客项目

你可以使用这些示例来了解如何配置你的 Next.js 应用以使用 `@opennextjs/cloudflare`，或者参考 [入门指南](/cloudflare/get-started)。

### Next.js Commerce 演示

[Next.js Commerce 演示应用](https://github.com/vercel/commerce/tree/v1) 可以与 `@opennextjs/cloudflare` 配合使用。你可以 [在此处](https://vercel-commerce-on-workers.web-experiments.workers.dev/) 查看其部署版本。
